**Honesty notes (spec §49):**
- **Ties:** ResearchMind does not beat the baseline on `citation_completeness` or
  `research_completeness` — on well-supported claims the naive baseline also surfaces the
  citation/dimension. On the single well-supported factual task (`cf_001`) both systems are
  correct — an honest tie.
- **Baseline "completeness" was inflated pre-correction:** the baseline reaches 1.0 completeness
  partly by accepting *unsupported* claims (it never rejects anything), which is exactly why
  `claim_accuracy`/`evidence_support` matter more. High completeness with low accuracy is worse,
  not better.
- **Cost trade-off (spec §38):** ResearchMind performs per-claim verification, provenance, and
  contradiction accounting the baseline skips — more compute per claim for the quality gain.
  On CPU Ollama this is bounded (verification/provenance/freshness are deterministic, no extra
  LLM calls beyond the pipeline's existing planning/clustering).

## Top real-world findings

1. ResearchMind's architecture adds **large, measurable value** over a conventional one-shot
   workflow on contradiction handling, provenance/no-false-live, temporal correctness, claim
   accuracy, and evidence support.
2. The value is **concentrated in exactly the dimensions the architecture provides** — a naive
   LLM baseline scores 0.0 on contradiction/provenance/temporal because it has no such machinery.
3. On **simple well-supported facts, the baseline ties** — the architecture's value is in hard
   cases (conflict, staleness, weak sources, cached/local provenance), not easy recall.
4. The **evaluation exposed one genuine quality defect** (temporal over-flagging), now fixed —
   proof the harness is diagnostic, not a rubber stamp.
5. **Research Again / monitoring add value only when evidence actually changes** — a repeat run
   scores 0.0 and noise is suppressed, as it should.
6. **Confidence is calibrated**: correct-supported claims outrank contested/unsupported ones;
   the baseline's flat confidence fails this.
7. **No false-live provenance** anywhere in ResearchMind; the baseline mislabels cached/local
   evidence as live in every applicable task.
8. **Memory/graph continuity** holds across runs on the longitudinal tasks (continuity 1.0).
9. Biggest **strength**: evidence traceability + honest uncertainty. Biggest **weakness vs
   baseline**: higher per-claim compute (the deliberate cost of verification).
10. **Not measured** (limitation): live-web collection/ranking quality and LLM-synthesis prose
    quality — the former needs a non-reproducible live environment, the latter is human-reviewed.

## Limitations (spec §47)

Fixture-based, deterministic, offline — a reproducible proxy for real-world evaluation, **not**
a live-web study. Sample is 18 claim tasks + 2 longitudinal across 6 categories. It does not
measure: live collection/ranking quality, LLM-synthesis prose (human-reviewed), or web-content
drift. The baseline is a legitimate naive workflow, not a strawman, but a stronger agentic
baseline (multi-step search + self-critique) is not implemented. Conclusions are about
**architecture value on realistic evidence**, not universal research superiority.
